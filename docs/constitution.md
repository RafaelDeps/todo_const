# todo-const Constitution

## Core Principles

### I. Strictly Python Stack
The project must be implemented exclusively using Python. No other programming languages are permitted for core logic or implementation.

### II. Local JSON Persistence
Data persistence must rely solely on local JSON files. Use of SQL databases or NoSQL databases is strictly prohibited.

### III. Code Quality & Standards
All Python code must adhere to PEP 8 standards. The use of Type Hints is mandatory. Naming conventions must strictly follow snake_case.

### IV. Resilience & I/O Integrity
Robust error handling must be implemented for all I/O operations. The application must handle scenarios where files are missing or corrupted without crashing.

### V. User-Centric UX & Error Handling
User-facing messages must be friendly and helpful. Technical error details and stack traces must never be displayed to the end-user.
